# Hindi Adult CI Auditory Training

GitHub Pages-ready static interface for the Hindi Adult Cochlear Implant Auditory Training working draft.

## Sequence
Home → Screening A–D → Section A (Modules 1–6) → Section B (Modules 7–12).

## Current implementation
- Data-driven Hindi stimuli.
- Explicit stimulus/options/correctIndex for closed-set tasks.
- Auditory-only visual hiding.
- Browser Hindi speech output (hi-IN).
- Session scoring.
- Responsive layout.
- GitHub Pages compatible; no build system required.

## Clinical status
This is a working clinical draft, **not a validated Hindi normative assessment**. It should not be used to establish normative cut-offs without local validation. Recorded professional Hindi audio, controlled noise/SNR, clinician/patient modes, persistent records and formal reporting should be added before clinical deployment.
